# Panel

## Зачем создано приложение
Panel описывает права доступа к административной панели и служит контейнером для разрешений, используемых в интерфейсе управления и мониторинга.

## Что делает
- Регистрирует набор системных разрешений для панели управления.
- Позволяет использовать эти права в Django admin/панелях без выделенного набора моделей.

## Модели и взаимодействие
- **PanelPermission** — техническая модель, в `Meta.permissions` фиксирует права: просмотр security-панели и управление пользователями. Сама модель не хранит данных, но позволяет регистрировать разрешения в системе.

## Возможные варианты улучшения
- Добавить роли (группы) и маппинг ролей на права для удобства администрирования.
- Ввести логирование выдачи/отзыва прав и закрепить в `core.SecurityEvent`.
- Расширить права до модулей приложений (чат, опросы, RCA).

## Улучшения с учетом пересечения с другими приложениями
- Привязать права панели к орг.структуре `rca` (например, права по орг.единицам).
- Использовать единый аудит из `core` для всех действий админов в `panel`.
- Совместить с `chat` для отдельного канала уведомлений о критичных действиях (например, изменениях пользователей).
