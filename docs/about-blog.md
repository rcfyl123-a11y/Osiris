# Blog

## Зачем создано приложение
Блог отвечает за публикацию новостей и информационных материалов внутри системы, чтобы пользователи могли получать актуальные объявления и контент в одном месте. Приложение закрывает базовую потребность в новостной ленте без сложной редакторской инфраструктуры.

## Что делает
- Хранит новостные записи с заголовком, кратким описанием, полным текстом и изображением.
- Управляет флагом публикации и временем создания/обновления записи.
- Гарантирует сортировку по времени создания (новые выше).

## Модели и взаимодействие
- **News** — основная сущность записи блога: поля `title`, `summary`, `body`, `image`, `is_published`, `created_at`, `updated_at`. Записи упорядочиваются по времени создания, без внешних связей.

## Возможные варианты улучшения
- Добавить статусы публикации (черновик/на модерации/в архиве) и историю публикаций.
- Ввести категории и теги, чтобы поддерживать фильтрацию и тематические ленты.
- Добавить версионирование текста или хранение правок для аудита.

## Улучшения с учетом пересечения с другими приложениями
- Связать новости с орг.структурой из RCA (например, публиковать записи для конкретной `Org`).
- Использовать механизмы безопасности из `core` для протоколирования просмотров/скачиваний вложений (если появятся). 
- Добавить рассылку уведомлений в `chat` (например, оповещение о важных новостях в групповых чатах).
