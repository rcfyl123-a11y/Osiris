# Blog

## Назначение
Блог отвечает за публикацию новостей и информационных материалов внутри системы, чтобы пользователи могли получать актуальные объявления и контент в одном месте. Приложение закрывает базовую потребность в новостной ленте без сложной редакторской инфраструктуры.

## Основные сценарии
- Просмотр списка новостей и карточки публикации.
- Создание и редактирование новости сотрудниками, имеющими доступ.
- Управление публикацией через флаг `is_published`.

## Модели и инварианты
- **News** — основная сущность записи блога: поля `title`, `summary`, `body`, `image`, `is_published`, `created_at`, `updated_at`.
- Новости сортируются по времени создания (новые выше).
- Внешних связей нет.

## Интеграции
- Пока отсутствуют прямые связи с другими приложениями.
- Потенциальные интеграции: связь новостей с орг.структурой (`rca`), уведомления в `chat`.
