# Chat

## Зачем создано приложение
Чат предоставляет встроенную коммуникацию для сотрудников и команд, позволяя обсуждать задачи и обмениваться файлами внутри системы без внешних мессенджеров.

## Что делает
- Создает личные и групповые комнаты.
- Управляет участниками, ролями и состояниями (вступление, выход, mute).
- Хранит сообщения с поддержкой ответов и формата текста.
- Принимает и хранит файлы/изображения как вложения к сообщениям.

## Модели и взаимодействие
- **ChatRoom** — комната чата. Имеет тип `direct`/`group`, название, описание, связь с орг.единицей `Org` (из RCA), создателя и статус архивации. Для личных чатов хранит `direct_key`.
- **ChatMembership** — связь пользователя и комнаты с ролью, временными метками и флагом mute. Обеспечивает уникальность пары `room`/`user`.
- **ChatMessage** — сообщение в комнате: отправитель, тело, формат, метаданные, время отправки/редактирования, soft-delete, ссылка на сообщение-родитель для ответов.
- **ChatAttachment** — вложение (файл/изображение) к сообщению с типом, размером и временем загрузки.

## Возможные варианты улучшения
- Добавить read-receipts по каждому сообщению (не только `last_read_at` в членстве).
- Ввести механизмы модерации/антиспама (фильтры, rate limits).
- Хранить реакции/эмодзи на сообщения и упоминания.

## Улучшения с учетом пересечения с другими приложениями
- Интеграция с `rca`: автоматическое создание групповых комнат по орг.единицам и актуализация участников при кадровых изменениях.
- Интеграция с `core`: логирование чувствительных действий (удаление сообщений/вложений, управление ролями) в `SecurityEvent`.
- Связь с `polls`: публикация опросов в чат с быстрыми ссылками и уведомлениями о старте/закрытии голосований.
