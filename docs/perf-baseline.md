# Performance baseline

## Горячие страницы и запросы

Считаем «горячими» (часто используемыми и чувствительными к задержкам) следующие страницы:

- **Chat room detail** — просмотр деталей комнаты и ленты сообщений.
- **Polls vote page** — страница голосования и отправка выбора.
- **RCA employee list** — список сотрудников с фильтрами.
- **Panel dashboard** — базовый дашборд панели.

## Healthcheck

Запуск базовой проверки:

```bash
python manage.py project_healthcheck
```

Команда проверяет наличие таблиц приложений `core`, `polls`, `chat`, `rca`, печатает версию Python/Django,
флаг `DEBUG`, вендор базы данных и выполняет типовые ORM-запросы с замером времени.

### Что считать нормой

- **Локальная разработка**: каждый запрос в пределах ~50–150 мс.
- **Staging/production**: ориентируйтесь на исторические значения; регрессии в 2× и более считаются
  критичными и требуют анализа.
- Если таблицы отсутствуют, запросы для соответствующего приложения будут пропущены — это сигнал
  проверить миграции и состояние базы.

Используйте результаты healthcheck для отслеживания трендов и фиксации базовой линии
производительности при изменениях конфигурации или инфраструктуры.
