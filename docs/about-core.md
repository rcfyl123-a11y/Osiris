# Core

## Зачем создано приложение
Core концентрирует общие доменные сущности, связанные с безопасностью, инвентаризацией приложений и учетом рабочих мест, чтобы другие приложения могли опираться на единые источники данных и журналирование.

## Что делает
- Фиксирует события безопасности и чувствительных действий пользователей.
- Хранит сведения о рабочих местах и их разрешенных пользователях.
- Отслеживает IP-адреса пользователей, историю визитов и загрузок.
- Ведет реестр приложений с хешами для контроля целостности.

## Модели и взаимодействие
- **SecurityEvent** — журнал событий безопасности (тип события, пользователь, IP, путь, метод, статус, причина).
- **Workstation** — рабочее место с IP, метками, локацией и списком разрешенных пользователей (M2M).
- **UserIPRecord** — история IP для пользователя с последним посещением/скачиванием.
- **DeniedIPAttempt** — попытки доступа с заблокированных IP.
- **AppInventory** — инвентаризация приложений и их файловых хешей.

## Возможные варианты улучшения
- Ввести категории риска и SLA на обработку SecurityEvent.
- Добавить автоматическое устаревание или архивирование IP-записей.
- Расширить инвентаризацию приложений до мониторинга зависимостей и миграций.

## Улучшения с учетом пересечения с другими приложениями
- Синхронизировать `Workstation` с `polls.Workplace`, чтобы исключить дублирование сущностей рабочих мест.
- Использовать `SecurityEvent` как единый аудит для `panel`, `chat`, `polls` (изменения ролей, публикации опросов, удаление сообщений).
- Сопоставлять IP-данные пользователей с кадровыми сведениями `rca` для улучшенной аналитики доступа.
