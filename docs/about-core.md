# Core

## Назначение
Core концентрирует общие доменные сущности, связанные с безопасностью, инвентаризацией приложений и учетом рабочих мест, чтобы другие приложения могли опираться на единые источники данных и журналирование.

## Основные сценарии
- Регистрация и аутентификация пользователей.
- Аудит действий и контроль IP-доступа.
- Ведение инвентаризации приложений и рабочих мест.

## Модели и инварианты
- **SecurityEvent** — журнал событий безопасности (тип события, пользователь, IP, путь, метод, статус, причина).
- **Workstation** — рабочее место с IP, метками, локацией и списком разрешенных пользователей (M2M).
- **UserIPRecord** — история IP для пользователя с последним посещением/скачиванием.
- **DeniedIPAttempt** — попытки доступа с заблокированных IP.
- **AppInventory** — инвентаризация приложений и их файловых хешей.
- **AppInventoryHistory** — история изменений инвентаризации приложений.
- Инвариант: события безопасности пишутся в `SecurityEvent` для чувствительных действий.

## Интеграции
- **Auth**: большинство моделей связаны с `AUTH_USER_MODEL`.
- **Panel**: аудит просмотров и действий админов через `SecurityEvent`.
- **Polls**: пересечение домена рабочих мест с `polls.Workplace`.
- **RCA**: сопоставление IP-данных с кадровыми сведениями.
- ADR: [Workstation vs Workplace](adr/0001-workstation-vs-workplace.md).

## Права доступа и безопасность
- IP-контроль и аудит реализованы в `osiris/apps/core/middleware.py` (IPAllowlistMiddleware, resolve_client_ip).
- События пишутся в `SecurityEvent`, блокировки — в `DeniedIPAttempt`.

## Производительность
- Аудит и IP-логирование выполняются на каждом запросе; важно следить за объёмом записей.
- Потенциальные узкие места: выборки по IP/пользователю без индексов (см. perf-baseline).
