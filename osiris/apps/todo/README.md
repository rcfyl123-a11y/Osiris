# TODO Приложение на Django

Простое веб-приложение списка дел (TODO) на Django с использованием SQLite и Bootstrap интерфейса.

## Особенности

- Добавление новых задач
- Отметка выполнения задач
- Удаление задач
- Административная панель
- Адаптивный дизайн с Bootstrap
- Поддержка русского языка

## Требования

- Python 3.8+
- Django 6.0.1

## Установка

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd todo_app
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Выполните миграции:
```bash
python manage.py migrate
```

4. Создайте суперпользователя:
```bash
python manage.py createsuperuser
```

5. Запустите сервер разработки:
```bash
python manage.py runserver
```

Приложение будет доступно по адресу: http://127.0.0.1:8000

Админка: http://127.0.0.1:8000/admin

## Использование

- Главная страница: http://127.0.0.1:8000 - список задач с возможностью добавления
