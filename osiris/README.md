# Проект Osiris

Модульный Django‑фреймворк для масштабируемых веб‑приложений.

## Структура

```
osiris/
├── __init__.py
├── manage.py            # Management-утилита
├── config/              # Настройки и ASGI/WSGI конфиги
├── apps/                # Приложения
│   ├── core/            # Основные функции (авторизация, регистрация, главная страница)
│   ├── blog/            # Новости и блог
│   └── rca/             # Штатное расписание (SCD2)
└── templates/           # Общие шаблоны
```

## Возможности

- **Модульная архитектура**: приложения сгруппированы в `apps/`.
- **Автообнаружение приложений**: пакеты в `osiris/apps` подключаются к `INSTALLED_APPS` автоматически.
- **Масштабируемость**: проще добавлять новый функционал отдельными модулями.

## Установка

1. Клонируйте репозиторий.
2. Установите зависимости: `pip install -r requirements.txt`.
3. Выполните миграции: `python manage.py migrate`.
4. Запустите сервер: `python manage.py runserver`.

## Добавление новых приложений

1. Создайте Django‑приложение в каталоге `osiris/apps/<app_name>`.
2. Создайте файл `apps.py` и объявите в нём класс, наследующийся от `django.apps.AppConfig`.
3. Автодискавери ищет `osiris.apps.<app_name>.apps`, берёт первый найденный `AppConfig` и регистрирует его.
4. Если `apps.py` отсутствует или модуль не импортируется, приложение будет пропущено с предупреждением в логах.

## Запуск проекта

```bash
cd osiris
python manage.py runserver
```

Приложение будет доступно по адресу http://127.0.0.1:8000/

## Текущие приложения

- **Accounts**: регистрация и авторизация.
- **Blog**: публикация новостей и страницы блога.
- **RCA**: штатное расписание с историей изменений (SCD2).
